## Проверка

Локальный сервер: `node dev-server.js`, адрес http://127.0.0.1:4173/.

Браузерная проверка `node tools/verify-site.cjs`: 33 страницы, 1440 и 375 px; одинаковая навигация, ошибки JavaScript, локальные ссылки, повторяющиеся id, переполнение по ширине. Проверяются фильтры и их сброс, вкладки видео, выбор продукта для ERP, редирект EmScan. Скриншоты сохраняются в TEMP/neiroiconica-review.

Проверка не отправляет заявки и не скачивает полные видео; внешние запросы блокируются для воспроизводимости. Старые скрытые руководства имеют по два h1 в исходном шаблоне: это исключение для noindex-страниц, их содержание в рамках этой работы не перерабатывалось.

Историческая новость «Образовательный модуль для студентов Университета Сириус» не переименована: это событие, а не старое название продукта в каталоге.
